# The first fallback is preselected when nothing else matches

Accepted 2026-10-06 by the user's decision, to match Raycast ([Raycast deep dive](../research/raycast-deep-dive.md#root-search), its decision 4). It supersedes one provisional choice of #31: that a fallback row is never selected by itself, so that when nothing else matched, Enter did nothing until the user moved to a fallback ([aliases and fallbacks](../aliases.md#making-a-command-a-fallback), [current decisions](../current-decisions.md) item 10). It also supersedes the statements that follow from that choice in [root search](../root-search.md) and in the glossary's Fallback and No-results notice. The rest of #31 stands: which commands are fallbacks, the order they are offered in (the order the user turned them on), the text sent (the whole query, trimmed), and their place below every other result.

So when a query that is not blank lists nothing but fallbacks, root search selects the first fallback, as it selects the best match otherwise, and Enter sends it the query. The no-results notice still heads the list above the fallbacks. When anything else is listed, the best match is selected as before, and the fallbacks stay below it, unselected until the user moves to one.

This selection is root search's own, not the user's. A result that arrives later for the same query, such as a computed or an indexed result, takes the selection as a late best match does today, unless the user has moved it. Enter waits briefly for the current query's results, as Raycast's does (up to 300 ms) and as the root search specification adds. So a fallback is not sent text that a slower provider was about to answer.

#31 kept fallbacks unselected so that typed text reaches a command only when the user invokes it. That remains true: typing sends nothing, and Enter is the user's choice of a row that the notice and the selection both show. What the old rule cost was the commonest use of a fallback. A query that matched nothing made Enter do nothing, where in Raycast Enter hands the text to the first fallback, such as a web search. The user chose to match Raycast.
