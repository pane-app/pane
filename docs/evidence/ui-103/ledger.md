**Results:**

- **pass**: every parity check for the row passes (1 logical px for edges and baselines, 2 channel levels for flat fills, 4 levels for glyph cores), and so does every harness check.
- **accepted deviation (Dn)**: the row's parity checks pass, except those carrying a recorded disposition. Each disposition is listed by id below the table with its full text, as the comparison recorded it.
- **native-only**: no board authors the state, so nothing can be compared with the reference. The capture passes its harness checks (the fixture's declared layout against what its capture measures) and was looked at.
- **open deviation**: measured, differs from the reference, and has no accepted disposition.
- **reviewed by eye**: real-window captures with no reference at that configuration to compare against.
- **not covered**: no capture exists. The row names what covers it instead (window tests), or why nothing does.

Counts read `parity passed/failed/accepted; harness passed/failed` over the checks the row selects. The light (`-Theme light`) and glass variants are separate; see the README.
