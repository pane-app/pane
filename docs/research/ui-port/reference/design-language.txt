Pane

A fast, quiet launcher. Everything else is a plugin.

01
Keyboard first, mouse welcome
Every row, action and layout has a shortcut. Hover and click still work everywhere.
02
Nothing runs until you ask
The core is search, actions and settings. Plugins load on first use and unload when idle.
03
Glass that stays readable
Tint never drops below 55%, so text holds 4.5:1 on any wallpaper. Solid mode follows the OS.
04
Same muscle memory on every OS
One layout on macOS, Windows and Linux. Only the modifier keys change.
05
Plugins say what they touch
Network hosts, clipboard, files and screen are asked for up front, in plain words.
